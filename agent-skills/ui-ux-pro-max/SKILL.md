# UI UX Pro Max

Use product-level design judgment before implementation. The page should feel
intentional, distinctive, usable, and clear.

## Priority Order

1. Accessibility and legibility.
2. Message clarity and conversion path.
3. Responsive layout and interaction states.
4. Visual direction matched to product category.
5. Typography, color, spacing, and component rhythm.
6. Motion that supports meaning.
7. Final polish and perceived quality.

## Landing Page Design Rules

- Pick a clear art direction: editorial, product-led, technical, premium,
  playful, minimal, bold, data-rich, or immersive. Do not mix styles randomly.
- Establish hierarchy with scale, contrast, spacing, and position, not by making
  everything large.
- Use a purposeful palette with semantic accent colors; avoid gray-on-gray,
  one-hue pages, and arbitrary gradients.
- Use readable typography: base text around 16px, comfortable line height, and
  strong contrast.
- Make CTAs visually obvious, consistently styled, and reachable on mobile.
- Include loading, hover, focus, active, disabled, error, and empty states when
  the component can enter those states.
- Avoid horizontal scroll, fixed-width containers, clipped text, and layouts that
  require hover on touch devices.

## Motion And Interaction

- Use 150-300ms for most UI transitions.
- Animate transform/opacity instead of layout-heavy properties.
- Use staggered or scroll motion only when it helps users understand the page.
- Respect reduced motion and keep content usable without animation.
- Do not use infinite pulsing CTAs or decorative motion that competes with copy.

## Review Checklist

- Can a user understand the offer in five seconds?
- Is the next action obvious without reading every section?
- Does the page look credible and specific to this product?
- Does every visual asset help explain, prove, or sell the offer?
- Does the mobile layout preserve hierarchy and spacing?
- Are accessibility, SEO, and performance basics preserved?
