|----------|-------------|
| Orchestrator route -> worker executor | `/jobs` and `/jobs/sync` deliver untrusted job payloads into `runJob`. |
| Worker executor -> shell/sandbox | Validation and fix loops execute commands that must remain allowlist and sandbox guarded. |

| Worker executor -> external providers | Data-collector and media branches call existing provider modules and must not expand behavior. |
| Worker executor -> orchestrator callback | `reportResult` posts final status, commands, branch, error, diff, sandbox, and cost fields. |
