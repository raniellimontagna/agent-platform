- D-01 Provider Cutover Scope: Plane is the only active provider for new intake, approval, reports, auto-merge labels, scheduler-created cards, and card-run history.
- D-02 Compatibility Strategy: retain legacy Linear columns and prove old rows resolve through generic fields or explicit migration-only compatibility.
- D-03 Test-First Requirements: add Plane-focused characterization tests before removing active Linear paths.
- D-04 Documentation and Operations: active docs must say Plane-only operation and legacy/migration-only Linear support.
- D-05 Destructive Boundary: do not drop columns, delete package support, delete historical docs, or remove deployed route support without explicit confirmation.
