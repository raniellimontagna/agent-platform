| Boundary | Description |
|----------|-------------|
| Plane/legacy provider -> public webhook route | Untrusted external webhook bodies cross into Hono route parsing and signature verification. |
| Webhook route -> run database and BullMQ | Label transitions trigger run creation, cancellation, approval resolution, and queue jobs. |
| Legacy Linear compatibility -> active Plane system | Compatibility route must remain gated and must not become an active provider default. |
| Planner/executor -> package manager | Existing stack is sufficient and package installs would expand supply-chain exposure. |
